# decksql

Deck timestamps and sql durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/decksql/

## Install / run

```bash
git clone https://github.com/theworker02/decksql.git
cd decksql
node src/cli.js
node --test
```
